Your weekly rhythm

A system that only runs when you feel like it is a mood. This is the rhythm that keeps it a system. It takes about 20 minutes a week.

Sunday night: the Ledger (15 minutes)

  • Mark each day for each commitment: kept, floor, missed or not scheduled.
  • Write the number: for example, 13 of 15 kept. A floor day counts as kept.
  • Name the one miss that keeps coming back, in one line.
  • Write one change for Monday: smaller, earlier or clearer.
  • Send your number to your partner or post it on the call. A number nobody sees is easy to round up.

Monday morning: lock it (2 minutes)

Read your sentence. Check that every commitment still has a day, a time and a place this week. If the week is already crowded, decide now which ones run on the floor.

Wednesday: the floor check (1 minute)

Midweek is where plans quietly die. Ask one question: is anything slipping? If yes, drop to the bad-day version on purpose instead of letting it go to zero.

Second Tuesday: the call

Bring your last four scorecards and one miss you want help with. See the call lesson.
